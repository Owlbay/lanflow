## 1. 产品定位与已定决策

**一句话**：一个轻量、原生风格的 Mihomo 桌面客户端，只做日常翻墙最常用的事：导入订阅、选节点、开代理、看状态。

**目标用户**：已有机场订阅、会用 Clash 类软件，但不想折腾覆写、脚本和规则的用户。

**已定决策**

| 决策 | 结论 |
| --- | --- |
| 平台 | 先做 macOS + Windows，iOS 之后再做 |
| UI 框架 | MyGo 原生 UI（Go 绘制，不用 WebView） |
| 外观 | 贴近系统原生，不做品牌化视觉 |
| 开关 | 「内核」和「系统代理」是两个独立开关 |
| 导航 | 侧边栏 10 项，分三组：概览、代理、订阅 ｜ 连接、日志、规则 ｜ 网络、统计、检测；「设置」单独放在底部 |
| 高级配置 | DNS、嗅探、覆写、外部资源放进设置的分栏；默认「跟随订阅」，需要时才由澜流接管 |
| 概览主视觉 | 出口地图：从你所在城市到各出口的弧线，替代「当前出口」卡片 |

优先级标记：**P0** = v0.1 必须有；**P1** = v0.2 日常使用；**P2** = v0.3 之后。设计稿应覆盖 P0 和 P1，P2 只需预留位置。

## 2. 设计原则

1. **一眼看懂状态**：是否在代理、走哪个节点、用哪份订阅，在任何页面都能看到。
2. **常用操作两步内完成**：开关代理、切换节点、切换模式，在托盘里也能做。
3. **不暴露配置细节**：DNS、嗅探、规则交给订阅，界面只放少量开关。
4. **失败不破坏现状**：校验或更新失败时，继续使用上一份可用配置，并说明原因和处理办法。
5. **像系统自带的工具**：参照 macOS「系统设置」「活动监视器」和 Windows 11「设置」，不做花哨的仪表盘。

## 3. 视觉规范

### 3.1 颜色

不定义品牌色，所有颜色取自系统主题，浅色和深色跟随系统。

| 用途 | 取值 |
| --- | --- |
| 强调（选中、主按钮、链接、图表线） | 系统主题色 `Theme().Accent` |
| 文字 | 主要 / 次要 / 第三级灰，取系统文字色 |
| 背景 | 窗口背景、分组背景、分隔线，取系统色 |
| 状态 · 正常 | 系统绿：内核运行中、延迟低 |
| 状态 · 警告 | 系统橙：延迟中等、订阅即将到期 |
| 状态 · 错误 | 系统红：内核异常、超时、校验失败 |
| 状态 · 停止 | 第三级灰：未启动、未测试 |

状态色只用于小圆点、延迟数字和图标，不用来铺满大块背景。状态旁边始终配文字，不只靠颜色区分。

**路由配色**（仅出口地图）：主代理组用系统主题色，其他路由依次用系统紫、粉、青、橙。陆地点阵用第三级灰。

**延迟分级**：≤ 300 ms 为绿；301–800 ms 为橙；> 800 ms 或超时为红，超时显示文字「超时」；未测试显示灰色「—」。

### 3.2 字体

使用系统字体：macOS 为 SF Pro，Windows 为 Segoe UI Variable。速度、延迟、流量、端口等数字一律使用**等宽数字**（tabular figures），刷新时不跳动。日志和 YAML 使用系统等宽字体。

| 层级 | macOS | Windows | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 20 / 半粗 | 20 / 半粗 | 每页左上角标题 |
| 分组标题 | 13 / 半粗 | 14 / 半粗 | 设置分组、代理组名 |
| 正文 | 13 / 常规 | 14 / 常规 | 列表、表格、控件 |
| 辅助 | 11 / 常规 | 12 / 常规 | 时间、说明、单位 |
| 大数字 | 28 / 常规，等宽 | 28 / 常规，等宽 | 概览页实时速度 |

### 3.3 间距与尺寸

以 4 为基础单位：4、8、12、16、20、24、32。

| 项 | 值 |
| --- | --- |
| 页面内边距 | 24（左右）/ 20（上） |
| 分组之间 | 24 |
| 分组内行高 | 设置行 40；列表行 32；表格行 28；日志行 22 |
| 圆角 | 控件 6；分组容器 10 |
| 侧边栏宽度 | 200，不可拖动调整 |
| 窗口 | 默认 1180 × 780（首次启动时按屏幕可用区域缩小，至少留 40 的边距），最小 1000 × 680，记住上次的大小和位置 |
| 两栏布局 | 窗口宽度 ≥ 1100 时，设置等以分组为主的页面把分组排成两栏；网络、概览的主要内容始终两栏 |

### 3.4 图标

线性单色图标，16 px（侧边栏、工具栏）或 12 px（行内）。颜色与相邻文字一致，选中时跟随强调色。

| 位置 | 图标含义 |
| --- | --- |
| 概览 | 仪表 / 首页 |
| 代理 | 地球或分支 |
| 订阅 | 文档叠放 |
| 连接 | 双向箭头 |
| 日志 | 列表 / 终端 |
| 设置 | 齿轮 |
| 托盘 | 澜流标志的单色模板图标，分三种状态（见第 7 节） |

### 3.5 动效

只在以下场景使用：开关切换、列表增删、测速中的旋转指示、Toast 出现与消失、出口地图的请求动画（见 5.1「出口地图规则」）。其余动效时长 150–250 ms。系统开启「减少动态效果」时一律取消，地图改为静态细线。

## 4. 窗口与全局布局

```text
┌─────────────────┬──────────────────────────────────────────────────┐
│ ● ● ●           │  页面标题                        [页面工具栏操作]   │
│                 │                                                  │
│  ◉ 概览          │                                                  │
│  ◎ 代理          │                                                  │
│  ▤ 订阅          │                  页面内容区                        │
│ ─────────────── │          （主要内容一次放下，不整页滚动）             │
│  ⇅ 连接   23     │                                                  │
│  ≡ 日志          │                                                  │
│  ☰ 规则          │                                                  │
│ ─────────────── │                                                  │
│  ᯤ 网络          │                                                  │
│  ▥ 统计          │                                                  │
│  ◈ 检测          │                                                  │
│ ─────────────── │                                                  │
│  ⚙ 设置          │                                                  │
│ ─────────────── │                                                  │
│ ● 运行中 · 规则   │                                                  │
│ ↑ 12 KB/s       │                                                  │
│ ↓ 1.2 MB/s      │                                                  │
└─────────────────┴──────────────────────────────────────────────────┘
```

**侧边栏**

- 分三组：「概览、代理、订阅」是日常使用的主导航；「连接、日志、规则」看内核正在做什么；「网络、统计、检测」用于排查。「设置」单独放在底部。各组之间用分隔线隔开；⌘1–⌘9 依次对应这九项（⌘8 统计、⌘9 检测），⌘, 打开设置。
- 最小高度（680）下，三组、设置和底部状态条都完整可见，不出现滚动。
- 「连接」项右侧显示活动连接数徽标（P1），为 0 时隐藏。
- 底部**状态条**常驻，内容：状态点 + 内核状态 + 当前模式，下方两行显示上行和下行速度。点击回到概览。

| 内核状态 | 状态条显示 |
| --- | --- |
| 未启动 | 灰点 · 「未启动」，不显示速度 |
| 启动中 | 旋转指示 · 「启动中…」 |
| 运行中 | 绿点 · 「运行中 · 规则」 |
| 运行中，系统代理已开 | 绿点 · 「运行中 · 规则」，另加一行「系统代理已开启」 |
| 异常 | 红点 · 「内核异常」，点击跳转概览 |

**页面头部**：每页左上角为标题，右侧放本页操作，例如测速、导入、搜索。本页的工具栏在最小宽度下也要放得下（搜索框可缩窄）。

**不整页滚动**：默认窗口下每页的主要内容一次放下，页面本身不滚动；只有列表和表格（连接、日志、订阅规则、网站连通性、泄漏结果等）在自己的区域内滚动，并占满剩余高度。次要信息压成一行或标签（如网络页的本机网络、代理状态），很少用到的内容收在可展开的行里（如泄漏检查每一项的说明）。设置页以分组为主，内容超出时仍整页滚动，但在 ≥ 1100 宽度下分成两栏以减少滚动。字号和间距不因此缩小，仍按 3.2 / 3.3。

| 区域 | 内容 | 优先级 |
| --- | --- | --- |
| 开关区 · 内核 | 状态点、状态文字、版本、运行时长；右侧开关 | P0 |
| 开关区 · 系统代理 | 代理地址；右侧开关 | P0 |
| 开关区 · TUN | TUN 模式开关；首次打开引导安装权限组件（与「设置 › 代理」、菜单栏菜单共用同一流程） | P2 |
| 开关区 · 模式 | 分段控件：规则 / 全局 / 直连 | P0 |
| 出口列表 · 当前出口 | 主代理组最终节点（国旗、名称、延迟）、代理组、出口城市、「实测 / 推测」标签、该路由速度与连接数；点击跳转代理页并定位到该组 | P0（位置只按节点名推测） |
| 出口列表 · 其他路由 | 其他有活动连接的代理组，内容同上，字号较小 | P1 |
| 出口地图 | 陆地点阵、「你 · 城市」、出口城市标记、从你到各出口的请求动画：一次一个请求，线从你画向出口，到达后淡出、出口泛起涟漪，再发下一个；不画常驻的线 | P1 |
| 实测出口 | 卡片右上角按钮；对当前所有出口做一次 Cloudflare trace 探测，探测中显示「实测中…」 | P1 |
| 名不副实提示 | 实测城市与节点名不符时，列表项下方橙字「名称为台湾，实测出口在香港」 | P1 |
| 当前订阅 | 名称、已用/总流量进度条、到期日；点击跳转订阅页 | P1（P0 只显示名称） |
| 实时速度 | 当前上下行速度、60 秒折线图、本次累计流量、活动连接数 | P1 |
| 终端代理 | 一行命令，点击复制，复制后显示 Toast「已复制」 | P1 |
| 内存占用 | 内核内存，放在速度卡底部 | P2 |
| 出口 → 目标国家、点击弧线查看连接 | 见 [exit-map.md](exit-map.md) 第 4 节 | P2 |

**出口地图规则**

| 项 | 规则 |
| --- | --- |
| 路由来源 | 按活动连接的第一级代理组汇总；主代理组即使没有连接也始终显示，排第一 |
| 出口节点 | 沿代理组的当前选择逐级解析到最终节点（如「流媒体 → 节点选择 → 东京 03」） |
| 出口位置 | 优先使用 24 小时内的实测结果，否则按节点名推测；都没有时列表显示「位置未知」，地图不画该弧线 |
| 视野 | 自动缩放到你和所有出口城市，至少覆盖约 50° 经度；经度以你所在位置为中心展开，弧线走最短方向 |
| 同城多路由 | 弧线弯曲程度依次加大，避免重叠 |
| 请求动画 | 每条路由同一时间只有**一个**请求在路上：线从你出发逐渐画向出口，头部带亮点和淡光晕（缓入缓出，0.9–1.6 s，按弧线长度）→ 到达后整条线在 0.5 s 内淡出，同时出口外扩一圈涟漪（半径 4 → 14 px）→ 停顿 → 发出下一个请求 |
| 停顿时长 | 按该路由实时速度：> 700 KB/s 停 0.18 s；> 120 KB/s 停 0.5 s；其余停 1.1 s。没有流量时不发送 |
| 线的粗细 | 1.4–6 px，按实时速度取对数映射；速度先做平滑，避免跳变 |
| 无流量 | 只显示「你」和出口标记，不画线；列表仍显示该路由 |
| 减少动态效果 | 不播放请求动画，改为静态细线：有流量时实线，无流量时 25% 不透明度 |
| 切换节点 | 弧线终点平滑移动到新城市（正式版）；原型中直接重绘 |
| 全局模式 | 只显示 `GLOBAL` 一条路由 |
| 直连模式 | 不画弧线，列表显示「直连模式：流量不经过节点，无出口可显示」，不显示「实测出口」按钮 |

**「主代理组」规则**：取配置中第一个「选择」类型的代理组；用户可在代理页通过组的「⋯」菜单「设为主代理组」进行修改。

**开关联动**

| 操作 | 结果 |
| --- | --- |
| 内核关闭时打开「系统代理」 | 先启动内核，内核运行后再开启系统代理；内核启动失败则开关弹回，并显示错误 |
| 关闭「内核」 | 如系统代理由澜流开启，一并关闭；两个开关同时变为关闭 |
| 关闭「系统代理」 | 只关系统代理，内核继续运行 |
| 内核关闭时 | 模式分段控件可以切换（下次启动时生效）；地图只显示陆地和「你」，路由列表显示「内核未启动」，速度区显示「—」 |

**页面状态**

| 状态 | 表现 |
| --- | --- |
| 首次使用，没有订阅 | 整页替换为引导：图标 + 「还没有订阅」+ 主按钮「导入订阅」+ 次按钮「从文件导入」 |

| 内核文件 | 「内置」或路径 + 「更改…」 | P1 |
| 日志级别 | 下拉 | P1 |
| 重启内核 | 按钮 | P0 |
| 内核版本 · 已安装列表 | 卡片「内核版本」：当前版本、通道标签（内置 / 正式版 / 预发布）+「检查更新」；下方列出内置内核和每个已安装版本（版本、通道、安装日期、大小），各带「使用」「删除」（使用中和内置的不可删除）；「安装其他版本…」打开对话框，分段控件切换 正式版 / 预发布，列表显示日期和更新说明摘录，点「安装」下载并校验（`-v`、对当前运行时配置 `-t`），不自动切换 | P1 |
| 内核更新 | 开关「自动检查更新」（每天一次）、下拉「更新通道」（正式版 / 预发布 Alpha）、开关「自动安装更新」；发现新版本只提醒，打开自动安装才会下载并切换 | P1 |
| 外部资源 · 四个数据库地址 | 等宽文本框；默认指向 MetaCubeX/meta-rules-dat（`geox-url`） | P2 |
| 外部资源 · GEOIP 规则使用 | 分段：MMDB / DAT（`geodata-mode`）；切换后重新加载配置 | P2 |
| 外部资源 · 自动更新 | 开关 + 间隔下拉（`geo-auto-update`、`geo-update-interval`） | P2 |
| 外部资源 · 立即更新 | 按钮（`POST /configs/geo`）；显示上次更新日期；应用内置初始数据库，首次启动无需下载 | P1 |
| 配置文件夹 | 按钮 | P1 |
| 关于 | 版本、许可证、Mihomo 源码链接 | P0 |

已安装的内核并排保存在 `<数据目录>/cores/<版本>/mihomo` 并各带 `meta.json`（版本、通道、sha256、安装时间、来源）；`Settings.CoreVersion` 记录在用的版本（空 = 内置）。切换内核时先用新内核对当前 `runtime.yaml` 跑 `-t`，装有权限组件时先登记新内核，再停止旧进程并以同一配置、同一控制器套接字和端口立即启动新进程；系统代理和 DNS 全程不动，应用只感到不到一秒的中断；失败自动回退到原版本并提示。每次切换写入澜流日志。

常规、代理、内核栏的修改即时生效，不设「保存」按钮。需要重启内核的项（端口、局域网、GEOIP 模式）修改后自动热重载，失败时恢复原值并提示原因。

**DNS 与嗅探栏的「应用」机制**：这两栏的修改需要重新生成配置并重新加载内核，因此不即时生效。一旦有修改，页面底部固定出现应用栏「有未应用的更改。应用时会重新生成配置、校验，并让内核重新加载。」+「放弃」「应用」。有未应用更改时切换分栏，先确认是否放弃。

**高级栏（P3，完整开放 Mihomo 内核的入站 / 系统代理 / 虚拟网卡 / DNS / 嗅探能力）**

放日常用不到、但进阶用户会找的内核选项，全部对应 Mihomo 配置里的同名字段；**留空或关闭即不写入**，内核保持默认值，老用户什么都不会变。编辑后用与 DNS / 嗅探相同的「应用」栏提交，字段校验不通过时以 toast 指出第一处错误并保留输入。左右两列：

| 分组 | 设置项（对应字段） |
| --- | --- |
| 端口与局域网 | HTTP 端口（`port`）、SOCKS 端口（`socks-port`，与代理端口和彼此不得相同，被占用时拒绝）；允许 / 禁止的局域网地址（`lan-allowed-ips` / `lan-disallowed-ips`）；代理认证 `用户名:密码`（`authentication`）与免认证的地址（`skip-auth-prefixes`）。允许局域网连接而没有认证时，代理栏和这里都显示黄色提示 |
| 系统代理 | PAC 模式：系统代理改为自动配置脚本，澜流在 `127.0.0.1:<PAC 端口>`（默认 11233）提供 `/proxy.pac`，「不走代理的地址」变成 PAC 里的 DIRECT 规则，其余 `PROXY 127.0.0.1:<代理端口>; SOCKS5 …; DIRECT`；「国内域名直连」把 `.cn` 和常见国内网站加为 DIRECT。macOS 用 `networksetup -setautoproxyurl`，Windows 写 `AutoConfigURL`；关闭时和全局代理一样恢复之前的设置，异常退出后的恢复也认得 PAC |
| TUN | 严格路由（`strict-route`）、MTU、端点无关 NAT（`endpoint-independent-nat`）、只接管 / 不接管的网段（`route-address` / `route-exclude-address`，后者与 aTrust 兼容加入的合并）、DNS 劫持（`dns-hijack`，留空为 `any:53` 与 `tcp://any:53`）、网卡名称（`device`，留空为 `utun1700`）、只在 / 不在这些网卡上接管（`include-interface` / `exclude-interface`）。Linux 专有的 `auto-redirect`、redir / tproxy 端口不做 |
| 内核行为 | IPv6、统一延迟、TCP 并发、进程匹配（`find-process-mode`：默认 / 关闭 / 严格 / 总是）、TCP 保活间隔与空闲、禁用 TCP 保活、出站网卡（`interface-name`）、地理数据加载（`geodata-loader`）、禁用 ETag（`etag-support: false`）、保存 Fake-IP 映射（`profile.store-fake-ip`）、下载 User-Agent（`global-ua`）。`global-client-fingerprint` 已被内核移除，不提供 |
| DNS 高级 | 作用于当前生效的 dns 段（跟随订阅或接管均可）：本机 DNS 监听（`listen`）、优先 HTTP/3、缓存算法（`cache-algorithm`）、引导服务器（`default-nameserver`）、备用服务器（`fallback`）及其过滤（`fallback-filter` 的 geoip / geoip-code / ipcidr / domain） |
| 嗅探高级 | 不强制 DNS 映射（`force-dns-mapping: false`）；嗅探纯 IP 连接已在嗅探栏 |

热生效：HTTP / SOCKS 端口、TCP 并发、出站网卡、IPv6 走 `PATCH /configs`；PAC 相关只改系统代理；其余重新生成配置并重新加载。

┌──────────────────────────────────────────────────────────────────┐
│ › ● DNS     部分  仅遵守系统代理的应用由澜流解析域名   前往设置 › 代理 │
│ › ● IPv6    正常  本机没有可用的公网 IPv6                           │
│ › ● WebRTC  部分  浏览器的 WebRTC 会暴露真实 IP                     │
│ › ● IP 类型 正常  出口 45.76.211.38 · AS20473 Vultr · 机房 IP       │

| 分栏 | 内容 |
| --- | --- |
| 泄漏检查（第一栏） | 由网络页移来，占满整栏：检查 DNS 请求、IPv6 和 WebRTC 是否绕过代理，以及出口 IP 的类型，可附加一个域名参与 DNS 对比；一行一项，点击展开明细和说明。未通过（部分 / 泄漏）的项在行尾给出修复链接：DNS、DNS 对比 → 设置 › 代理（TUN 与「自动设置系统 DNS」）；IPv6 → 未开 TUN 时设置 › 代理，已开 TUN 时设置 › 高级（IPv6 与 TUN 路由）；WebRTC（浏览器设置）和 IP 类型（节点属性）没有链接 |

| 解锁检测 | 经所选出口各访问一次常用服务，列出可用性与判定地区 |

## 8. 关键流程

### 8.1 首次启动

```text
打开应用
  └─ 检查内核文件
       ├─ 找不到 → 概览显示「未找到 Mihomo 内核」提示条
       └─ 正常 → 概览空状态「还没有订阅」
                    └─ 导入订阅（6.1）→ 成功 → 自动启动内核
                         └─ Toast「已导入并启动」+ 系统代理开关旁出现提示气泡「打开以让系统流量走代理」
```

不自动开启系统代理，由用户手动打开。

### 8.2 日常使用

打开托盘 → 打开「系统代理」→ 需要时在「节点选择」子菜单中换节点。全程不需要打开主窗口。

### 8.3 切换订阅

订阅页双击 → 行内显示旋转指示 → 校验 → 热重载 → 「当前」标签移到这一行 → Toast「已切换到 备用机场」。失败时弹出 6.3 对话框，当前订阅不变。

### 8.4 内核意外退出

状态条和托盘变为红色 → 系统通知「Mihomo 内核意外退出」→ 自动重启一次 → 再次失败时概览显示红色提示条，系统代理自动关闭，避免断网。

## 10. 文案规范

- 语气简短、平实，用「你」或省略主语；按钮用动词：「导入」「更新」「删除」。
- 错误文案写清三件事：发生了什么、现在的状态、可以怎么做。例：「订阅更新失败：连接超时。仍在使用上次的配置。可稍后重试，或在编辑中开启“通过代理更新”。」
- 数字与单位之间加空格：`86 ms`、`1.2 MB/s`、`32.5 GB`。速度自动换算 B/s → KB/s → MB/s，保留 1 位小数。
- 时间：1 小时内显示「x 分钟前」，当天显示「今天 10:21」，更早显示日期。

**术语表**（界面统一用左列）

| 界面用词 | 不用 |
| --- | --- |
| 内核 | 核心、Core |
| 系统代理 | 全局代理、SysProxy |
| 订阅 | 配置、Profile（「查看配置」除外） |
| 节点 | 服务器、Proxy |
| 代理组 | 策略组、Group |
| 模式：规则 / 全局 / 直连 | Rule / Global / Direct |
| 测速 | 延迟测试、Ping |
| 连接 | 链接 |
| TUN 模式（增强模式） | 虚拟网卡模式 |
